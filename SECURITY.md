# Security Policy

## Supported versions

Security fixes are applied to the latest source version and the latest published Chrome Web Store release.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability that could put users at risk. Instead, submit a private GitHub security advisory at:

https://github.com/NguyenHungCuongg/Beeyond-Limits/security/advisories/new

Include:

- The affected version or commit.
- Reproduction steps or a proof of concept.
- The potential impact.
- Any suggested remediation, if available.

Please allow a reasonable period for investigation and remediation before public disclosure. Non-sensitive bugs can be reported through the normal issue tracker.

## Security principles

Beeyond Limits is designed to keep user data local, execute only packaged code, request permissions for disclosed features, and avoid collecting page content or authentication data.
